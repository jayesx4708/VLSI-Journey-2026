# VLSI-Journey-2026

This repository documents my 2026 journey into VLSI Design, starting from the fundamentals and progressing toward RTL Design, Verilog/SystemVerilog, digital IC design, verification, and industry-oriented projects.

I am currently an Electronics & Communication Engineering (ECE) student and this repository serves as my public learning log, project portfolio, and preparation roadmap for a career in the VLSI industry.
